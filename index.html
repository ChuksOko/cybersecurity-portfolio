Featured Project

ELK Stack SIEM — SSH Brute-Force Detection

Built a centralized logging pipeline for authentication events, then simulated SSH brute-force attacks with Hydra to validate detection. Custom Kibana dashboards and KQL queries surfaced the attack in real time, and the full investigation — from detection logic to mitigation — is documented end to end. This project touches SIEM, detection engineering, log analysis, and incident response, which is why it's the clearest single example of how I'd operate inside a SOC.
