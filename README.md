## 🧪 Lab Projects

The following projects demonstrate hands-on experience across security operations, detection engineering, cloud security, vulnerability assessment, and incident response using isolated lab environments and industry-standard tools.

### 1. 🏗️ Integrated Cybersecurity Homelab
Designed and integrated a 4-VM cybersecurity homelab featuring Kali Linux, DVWA protected by ModSecurity, an ELK Stack SIEM, and a Cowrie SSH honeypot. Integrated offensive and defensive security tools into a single enterprise-style lab to simulate attacks, centralize logging, validate security controls, and investigate incidents in an isolated environment.

**Key Outcomes**

- 4 integrated virtual machines
- Multiple attack simulations
- Centralized logging and monitoring

`VirtualBox` · `Kali Linux` · `DVWA` · `ModSecurity` · `Apache` · `ELK Stack` · `Filebeat` · `Cowrie`

🔗 **[GitHub Repository →](https://github.com/ChuksOko/cybersecurity-homelab)**

---

### 2. 🛡️ WAF Defense Validation — ModSecurity + Apache
Validated web application firewall effectiveness by deploying ModSecurity with the OWASP Core Rule Set in blocking mode. Successfully prevented SQL Injection and Cross-Site Scripting attacks against DVWA and PrestaShop after confirming both vulnerabilities were exploitable before deployment.

**Key Outcomes**

- Blocked all four simulated attacks
- Enforced HTTP 403 responses
- Eliminated successful web exploitation after WAF deployment

`ModSecurity` · `Apache` · `OWASP CRS` · `SQLi` · `XSS` · `DVWA` · `PrestaShop` · `curl`

🔗 **[GitHub Repository →](https://github.com/ChuksOko/-WAF-Defense-Validation-Lab---ModSecurity-Apache)**

---

### 3. 🔍 SSH Brute-Force Detection — ELK Stack SIEM
Engineered an ELK-based SIEM pipeline that collected Linux syslogs, detected simulated Hydra SSH brute-force attacks in real time, and visualized attack activity using custom Kibana dashboards. Documented indicators of compromise and recommended mitigation strategies.

**Key Outcomes**

- Detected simulated Hydra SSH brute-force activity in real time
- Custom Kibana dashboard
- Extracted and documented Indicators of Compromise (IoCs)

`Elasticsearch` · `Logstash` · `Kibana` · `Hydra` · `KQL` · `Syslog` · `Ubuntu`

🔗 **[GitHub Repository →](https://github.com/ChuksOko/ELK-SSH-Bruteforce-Detection)**

---

### 4. ☁️ Cloud Privilege Escalation Simulation — AWS IAM
Simulated an AWS IAM privilege escalation attack by exploiting an overly permissive iam:AttachUserPolicy permission, escalated to administrator privileges, remediated the misconfiguration, and verified least-privilege enforcement.

**Key Outcomes**

- Administrator privilege escalation demonstrated
- Misconfiguration remediated
- MITRE ATT&CK T1098 mapped

`AWS IAM` · `AWS CLI` · `PowerShell` · `Privilege Escalation` · `Least Privilege` · `MITRE ATT&CK T1098`

🔗 **[GitHub Repository →](https://github.com/ChuksOko/-Cloud-Privilege-Escalation-Simulation---AWS-IAM)**

---
